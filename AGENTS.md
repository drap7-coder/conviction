## Cursor Cloud specific instructions

This is a single Next.js 16 (App Router, Turbopack) app named `conviction`. Package manager is **npm**. Standard commands live in `package.json`: `npm run dev` (port 3000), `npm run build`, `npm run typecheck` (`tsc --noEmit` — there is no ESLint/lint script), and `npm run test` / `npm run test:watch` (Vitest).

- The app runs fully in **guest mode with no external services**: no database, KV, or auth provider is required to boot and use it. Auth (`auth.ts`) falls back to JWT sessions and the watchlist persists to a local JSON file under `.conviction/` when Neon/Vercel KV env vars are absent. `npm run dev` alone is enough to exercise the product end-to-end (root `/` redirects to `/pulse`).
- The workspace header tape is a **scrolling strip of symbols and session %**: DIA, SPY, QQQ, GLD, BTC, then five trending names. No dollar prices, no spelled-out index names, no “Markets” label, no VIX/10Y. Pause only on hover of the tape itself (not `:focus-within` — a focused quote link would freeze the strip). Honor `prefers-reduced-motion` (static, swipe to see the rest). Loop is **20s desktop / 16s phone** so motion is obvious in a short look. The site-wide reduced-motion nuke (`* { animation-duration: 0.01ms !important }`) must not win when motion is allowed — `.market-tape-track` restores duration/iteration under `prefers-reduced-motion: no-preference`. To verify motion, do **not** leave the cursor on the tape (hover pauses it). Do not put ETF share prices next to index labels.
- SEO lives in `src/lib/site.ts` + `src/lib/seo.ts`. Public search/share title is “CONVICTION — Who’s buying the stocks you follow”. Do not put “Evidence Detection” or “Ownership Signals” in titles or meta descriptions — those read like a category, not the product. Pulse is the canonical home, so `/pulse` uses the brand title (absolute, no “Pulse · CONVICTION”) for Google and SMS/iMessage cards. Other routes use `pageMetadata()` so title, canonical, Open Graph, and Twitter stay in sync. Canonical host is `www.gotconviction.com` (override with `SITE_URL` / `NEXT_PUBLIC_SITE_URL`). Apex and the production Vercel alias 308 there in `next.config.ts`; `/` 308s to `/pulse`. Screen-reader `h1.sr-only` on Pulse / News / Watchlist / Portfolio / Smart Money is intentional — do not add a visible second lede.
- Heatmaps share one tile language (no pulsing status dots, uniform tiles, one-line names with ellipsis, brokerage teal/red fills from `src/lib/display/heat-color.ts`). **Quote grids** (Watchlist, Trending) show last `$` plus session `%`. **Pulse index/sector heatmaps are `%` only**. On phones every heatmap is **2-across** (including `--uniform` / `compact`); do not leave a 3-col mobile rule that loses to desktop `auto-fill`. Grids with more than 6 tiles collapse behind `HeatmapGrid` (“Show N more”) — desktop still shows the full set. Pulse `.market-heatmap` is a 6-track grid declared *after* the shared `--uniform` auto-fill (same specificity), so `.pulse-page .market-heatmap--uniform` must stay later in `globals.css` and keep `repeat(auto-fill, minmax(150px, 1fr))` or More markets tiles crush to ~60px. The phone 2-col `767px` rule must stay after that Pulse block. More-markets desktop tracks are `repeat(2, minmax(0, 1fr))` with `min-width: 0` on children — do not revert to bare `1fr 1fr`. Pulse heatmaps are title + tiles only — no narrative cards under Major Indexes or Sectors. Pulse Indexes and Trending have no `ProductStage` hero — the page starts on the view switcher, then heatmaps or trending. Do not put the news-headline / S&P–VIX–10Y stage back. Pulse Trending is the Active names heatmap only — no ticker chip row with +/× under it. That chip row is watchlist editing, not a market scan. More markets is Commodities (USO / GLD / SLV / UNG), Crypto (BTC / ETH), and International (six countries). Do not bring back the Themes heatmap or Solana. News has no `ProductStage`. The first Brief story (`visibleThemes[0]` in `.pulse-news-brief-grid`) may be a full-width image hero (`grid-column: 1 / -1`; 16:9 media when `imageUrl` is present, image | copy from ~768px, stacked on phones; hide the media box if the photo is missing or fails). That photo is the article’s own RSS or `og:image`/`twitter:image` (Google News wrappers are unwrapped first); never invent stock or unrelated images. All other stories stay text-forward cards (theme leads keep summary / why / assets; extra headlines use the same card chrome without repeating that essay). No wire list. No second lede before the first headline. Page heroes use canvas tokens (`var(--card)` / `var(--ink)`). Smart Money has one `ProductStage` per tab (Institutions vs Politicians) — do not put a shared “institutions and lawmakers” hero above the switcher, and do not stack a second insight-card lede under it. Do not special-case Smart Money metrics to a tighter/blue layout. Company dashboard catalyst is `CompanyEvidenceCard` (watchlist brief data in SignalBlock language: kind, headline, why, next proof, proof status) — do not drop watchlist `for-you-feed-card` chrome onto the company page. Watchlist has no `ProductStage` hero and no Updates / Higher / Lower strip — it is heatmap + composer. Sector pages still use `MaterialNewsCard`.
- Portfolio Study Mode keeps each template’s design brief (principle, how it’s built, what breaks it, illustrative history, sleeve roles) plus the allocation ladder for target weights and a concentration compare vs the live book. Historical performance cards keep colored ticks (annualized / best / worst). On phones those three stats stack as compact rows with a left tick so Worst never clips; How it’s built / What breaks it stack. Do not replace the study ladder with a plain ticker list. Do not bring back Live “pressure points” insight cards.
- Live Portfolio hero is **Fit + Reliance + posture sleeve moves** in the existing `ProductStage` — do not put “runs the book” / “Top three run the book” back, and do not add an Insights tab or pressure-points cards. Fit classifies the live book against the seven Study templates from sleeve mix (U.S. equity / intl / bonds / gold / commodities / cash), with ticker overlap as the tie-break: headline `Closest to Growth · 72` and a runner-up only when the next template is within ~8 points. Reliance is 0–100 “how much one idea has to be right” (high = concentrated) using the same 12 / 20 / 35 / 60 marks as `computeConcentration` / `computeRiskFlags` — not Conviction Score, not resilience, not a health grade. Copy like `Reliance 74 · NVDA 28% · Tech 61%` plus the existing 20% swing line. Three postures (Preserve / Balance / Grow) default from Fit; the user may overwrite. Recommendations are 2–4 concrete sleeve moves (`Trim NVDA −8pt` / `Add BND +10pt toward Three-Fund` / `Keep VTI`), not advice prose. Keep Value / Today / Largest, Book vs Benchmark, Capital Map, and holdings. One-line hedge: *Fit and Reliance describe this book — not a recommendation to trade.* Optional quiet “Moves vs your book” on Study only when a live book exists — never replace the study ladder.
- Portfolio page wrappers (`.portfolio-page`, `.pf`, `.pf-study`) must stay `grid-template-columns: minmax(0, 1fr)` with `min-width: 0`. The Study chip row is nowrap and will otherwise blow the implicit grid column past the phone viewport; `overflow-x: hidden` on `.app-shell` then clips the right side (performance % and the ends of sentences). Do not use `overflow-wrap: anywhere` on Study copy — wrap at word boundaries.
- Live market/filings data is fetched at runtime from public third-party APIs (Yahoo Finance, SEC EDGAR, FINRA, Nasdaq). Egress to some of these (notably `data.sec.gov`) may be blocked/403 in the cloud sandbox; the app degrades gracefully but some evidence panels may be empty.
- Known pre-existing test failures unrelated to setup: `tests/company-tickers.test.ts` hits the real SEC API and fails with `403` when egress is blocked; one case in `tests/conviction-score-adapters.test.ts` ("remaps 0–100 ring…") is time-dependent (uses default July 2026 filing dates without a fixed `now`) and fails once the current date is far enough past those dates. The other ~522 tests pass.
- Optional integrations are enabled only via env vars: `DATABASE_URL` (Neon Postgres, with SQL in `migrations/`), `AUTH_SECRET` + GitHub OAuth creds (NextAuth GitHub sign-in), `KV_URL`/`KV_REST_API_URL` (Vercel KV), `FMP_API_KEY`, `GOOGLE_BOOKS_API_KEY`, `CRON_SECRET`. None are needed for local development.
