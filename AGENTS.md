## Cursor Cloud specific instructions

This is a single Next.js 16 (App Router, Turbopack) app named `conviction`. Package manager is **npm**. Standard commands live in `package.json`: `npm run dev` (port 3000), `npm run build`, `npm run typecheck` (`tsc --noEmit` — there is no ESLint/lint script), and `npm run test` / `npm run test:watch` (Vitest).

- The app runs fully in **guest mode with no external services**: no database, KV, or auth provider is required to boot and use it. Auth (`auth.ts`) falls back to JWT sessions. **Watchlist SoT:** guests = `localStorage` (`conviction-watchlist`); signed-in = Neon `watchlist_entries`; ops/cron universe lives in `src/lib/evidence/sync-universe.ts` (KV `conviction:sync-universe`, legacy `conviction:watchlist` fallback) — never returned as a guest’s personal list. Daily sync queue = `buildDailySyncQueue()` (ops LRU, then popular Neon member tickers excluding `crowd-seed-*`, capped by `MAX_COMPANIES_PER_SYNC`). `npm run dev` alone is enough to exercise the product end-to-end (root `/` redirects to `/pulse`). Manage compose puts an **inline voice mic** inside the ticker field (`TickerCaptureActions`, Web Speech API) on desktop and mobile; Watchlist compose labels the ticker combobox (`inputAriaLabel` / `<label>`).
- Daily chrome is Pulse, Crowd, Portfolio, News, then **Menu**. Smart Money is not a tab-bar item — it lives under Menu → More. About and Q&A live under Menu → About, with the daily pages listed there too so new destinations scale without another bottom-bar item. Do not put Smart Money back on the tab bar. **Watchlist** lives on Portfolio behind a top `SurfaceSlicer` (`Live` / `Watchlist` / `Study`, URL `?view=watchlist` / `?mode=study`). Do not put Watchlist back on the tab bar. Legacy `/watchlist` permanentRedirect into Portfolio. **Movers**, **Crypto**, and **Intl** live on Pulse behind a top `SurfaceSlicer` (`Markets` / `Movers` / `Crypto` / `Intl`, URL `?view=movers` / `crypto` / `international`). **Markets** is gauges + Major Indexes + Commodities + US Sectors on one scroll. Do not put Movers/Crypto/Intl back in Menu or on the tab bar. Legacy `/sectors` permanentRedirects to `/pulse`; `/international` permanentRedirects into Pulse Intl. Add future pages to `menuNavPages` in `src/lib/nav-config.ts` unless they are daily. The Menu overlay is full-page (not a half sheet); `menuGroups` leads with **Your data** (Manage / Sign in), then Daily, More, About.
- **Crowd** (`/crowd`) is a daily tab — v1 network effects: classic “most held” / “most watched” across member books. Ten starter books (`crowd-seed-01`…`10` in `src/lib/crowd/seed-books.ts`) upsert into Neon when `DATABASE_URL` is set; without a DB the same fixtures power the board in memory. Aggregate only — never show who owns what. Rank rows show **share of books/lists** (`holderPct` / `watcherPct` as “N% of books” / “of lists”) beside the quote stack — not identity, not a share bar track. Board head shows quiet **seed vs live meta** (`crowd-board-meta` / `crowdBoardMetaLine`: book/list counts, starter vs live mix). Quiet **personal marker** (`crowd-you` / `crowdPersonalLabel`: one pill — “In your book”, “In your watchlist”, or “In your book & watchlist”) sits under the company name in `.crowd-id` — client-only intersection with the viewer’s own book/watchlist (same SoT as News); never from `/api/crowd`. No ProductStage hero; `SurfaceSlicer` for Held / Watched; hedge that starter books fill the board while membership is small. Keep Crowd on the tab bar (not Menu).
- The workspace header tape is a **scrolling strip of symbols and session %**: DIA, SPY, QQQ, GLD, BTC, then five trending names. No dollar prices, no spelled-out index names, no “Markets” label, no VIX/10Y. Pause only on hover of the tape itself (not `:focus-within` — a focused quote link would freeze the strip). Honor `prefers-reduced-motion` (static, swipe to see the rest). Loop is **20s desktop / 16s phone** so motion is obvious in a short look. The site-wide reduced-motion nuke (`* { animation-duration: 0.01ms !important }`) must not win when motion is allowed — `.market-tape-track` restores duration/iteration under `prefers-reduced-motion: no-preference`. - Portfolio page wrappers (`.portfolio-page`, `.pf`, `.pf-study`) must stay `grid-template-columns: minmax(0, 1fr)` with `min-width: 0`. The Study chip row is nowrap and will otherwise blow the implicit grid column past the phone viewport; `overflow-x: hidden` on `.app-shell` then clips the right side (performance % and the ends of sentences). Do not use `overflow-wrap: anywhere` on Study copy — wrap at word boundaries.
- Live market/filings data is fetched at runtime from public third-party APIs (Yahoo Finance, SEC EDGAR, FINRA, Nasdaq). Egress to some of these (notably `data.sec.gov`) may be blocked/403 in the cloud sandbox; the app degrades gracefully but some evidence panels may be empty. `/api/market/pulse` is **lean + cached** (~300s `unstable_cache` + CDN `s-maxage`): gauges (`^VIX`/`^TNX`) + scoreboard tickers only — no watchlist triage, macro-regime essays, sector-leadership classifiers, News RSS, or MDY/RSP on that route (News keeps `/api/market/news`; Movers keep `/api/market/trending`).
- Live SEC ticker coverage in `tests/company-tickers.test.ts` is gated behind `SEC_LIVE_TESTS=1` (data.sec.gov often 403s in sandboxes). One case in `tests/conviction-score-adapters.test.ts` ("remaps 0–100 ring…") is time-dependent (default July 2026 filing dates without a fixed `now`) and can fail once the calendar moves far past those dates. Cron / full evidence refresh require `CRON_SECRET` (fail closed). Admin resources (`/api/admin/resources`) accept the cron bearer **or** a signed-in user whose email is in `ADMIN_EMAILS` — never any signed-in user. Single-ticker evidence refresh stays available for company pages but is rate-capped (per-ticker cooldown + per-IP burst; cron bearer bypasses).
- Optional integrations are enabled only via env vars: `DATABASE_URL` (Neon Postgres, with SQL in `migrations/`), `AUTH_SECRET` + Google OAuth creds (NextAuth Google sign-in), `ADMIN_EMAILS` (comma-separated admin allowlist), `KV_URL`/`KV_REST_API_URL` (Vercel KV), `FMP_API_KEY`, `GOOGLE_BOOKS_API_KEY`, `CRON_SECRET`. None are needed for local development.
