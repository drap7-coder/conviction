## Cursor Cloud specific instructions

This is a single Next.js 16 (App Router, Turbopack) app named `conviction`. Package manager is **npm**. Standard commands live in `package.json`: `npm run dev` (port 3000), `npm run build`, `npm run typecheck` (`tsc --noEmit` — there is no ESLint/lint script), and `npm run test` / `npm run test:watch` (Vitest).

- The app runs fully in **guest mode with no external services**: no database, KV, or auth provider is required to boot and use it. Auth (`auth.ts`) falls back to JWT sessions and the watchlist persists to a local JSON file under `.conviction/` when Neon/Vercel KV env vars are absent. `npm run dev` alone is enough to exercise the product end-to-end (root `/` redirects to `/pulse`).
- The workspace header tape is a **scrolling strip of symbols and session %**: DIA, SPY, QQQ, GLD, BTC, then five trending names. No dollar prices, no spelled-out index names, no “Markets” label, no VIX/10Y. Pause only on hover of the tape itself (not `:focus-within` — a focused quote link would freeze the strip). Honor `prefers-reduced-motion` (static, swipe to see the rest). Loop is **20s desktop / 16s phone** so motion is obvious in a short look. The site-wide reduced-motion nuke (`* { animation-duration: 0.01ms !important }`) must not win when motion is allowed — `.market-tape-track` restores duration/iteration under `prefers-reduced-motion: no-preference`. To verify motion, do **not** leave the cursor on the tape (hover pauses it). Do not put ETF share prices next to index labels.
- SEO lives in `src/lib/site.ts` + `src/lib/seo.ts`. Public search/share title is “CONVICTION — Who’s buying the stocks you follow”. Do not put “Evidence Detection” or “Ownership Signals” in titles or meta descriptions — those read like a category, not the product. Pulse is the canonical home, so `/pulse` uses the brand title (absolute, no “Pulse · CONVICTION”) for Google and SMS/iMessage cards. Other routes use `pageMetadata()` so title, canonical, Open Graph, and Twitter stay in sync. Canonical host is `www.gotconviction.com` (override with `SITE_URL` / `NEXT_PUBLIC_SITE_URL`). Apex and the production Vercel alias 308 there in `next.config.ts`; `/` 308s to `/pulse`. Screen-reader `h1.sr-only` on Pulse / News / Watchlist / Portfolio / Smart Money is intentional — do not add a visible second lede.
- Heatmaps share one tile language (no pulsing status dots, uniform tiles, one-line names with ellipsis, brokerage teal/red fills from `src/lib/display/heat-color.ts`). **Quote grids** (Watchlist, Trending) show last `$` plus session `%` as separate figures — do not wrap the grid `%` in parens. **Pulse index/sector heatmaps are `%` only**. Company dashboard `CompanyQuoteCard` change chip is the exception: session `$` with muted `%` in parens (`+$2.51 (+0.35%)`), no middle-dot pair, teal/red on the dark quote canvas. On phones every heatmap is **2-across** (including `--uniform` / `compact`); do not leave a 3-col mobile rule that loses to desktop `auto-fill`. Grids with more than 6 tiles collapse behind `HeatmapGrid` (“Show N more”) — desktop still shows the full set. Pulse `.market-heatmap` is a 6-track grid declared *after* the shared `--uniform` auto-fill (same specificity), so `.pulse-page .market-heatmap--uniform` must stay later in `globals.css` and keep `repeat(auto-fill, minmax(150px, 1fr))` or More markets tiles crush to ~60px. The phone 2-col `767px` rule must stay after that Pulse block. More-markets desktop tracks are `repeat(2, minmax(0, 1fr))` with `min-width: 0` on children — do not revert to bare `1fr 1fr`. Pulse heatmaps are title + tiles only — no narrative cards under Major Indexes or Sectors. Pulse Indexes and Trending have no `ProductStage` hero — the page starts on the view switcher, then heatmaps or trending. Do not put the news-headline / S&P–VIX–10Y stage back. Pulse Trending is the Active names heatmap only — no ticker chip row with +/× under it. That chip row is watchlist editing, not a market scan. More markets is Commodities (USO / GLD / SLV / UNG), Crypto (BTC / ETH), and International (six countries). Do not bring back the Themes heatmap or Solana. News has no `ProductStage`. The first Brief story (`visibleThemes[0]` in `.pulse-news-brief-grid`) may be a full-width image hero (`grid-column: 1 / -1`; 16:9 media when `imageUrl` is present, image | copy from ~768px, stacked on phones; hide the media box if the photo is missing or fails). That photo is the article’s own RSS or `og:image`/`twitter:image` (Google News wrappers are unwrapped first); never invent stock or unrelated images. All other stories stay text-forward cards (theme leads keep summary / why / assets; extra headlines use the same card chrome without repeating that essay). No wire list. No second lede before the first headline. Page heroes use canvas tokens (`var(--card)` / `var(--ink)`). Smart Money has one `ProductStage` per tab (Institutions vs Politicians) — do not put a shared “institutions and lawmakers” hero above the switcher, and do not stack a second insight-card lede under it. Do not special-case Smart Money metrics to a tighter/blue layout. Company dashboard catalyst is `CompanyEvidenceCard` (watchlist brief data in SignalBlock language: kind, headline, why, next proof, proof status) — do not drop watchlist `for-you-feed-card` chrome onto the company page. Watchlist has no `ProductStage` hero and no Updates / Higher / Lower strip — it is heatmap + composer. Sector pages still use `MaterialNewsCard`.
- Portfolio Study Mode keeps each template’s design brief (principle, how it’s built, what breaks it, illustrative history, sleeve roles) plus the allocation ladder for target weights and a concentration compare vs the live book. Historical performance cards keep colored ticks (annualized / best / worst). On phones those three stats stack as compact rows with a left tick so Worst never clips; How it’s built / What breaks it stack. Do not replace the study ladder with a plain ticker list. Do not bring back Live “pressure points” insight cards.
- Live Portfolio hero is **Fit + Reliance + a comparison target + sleeve moves** in the existing `ProductStage` — do not put “runs the book” / “Top three run the book” back, and do not add an Insights tab or pressure-points cards. Fit classifies the live book against the seven Study templates from sleeve mix (U.S. equity / intl / bonds / gold / commodities / cash), with ticker overlap as the tie-break. Headline is the job of the book, Schwab-plain: `This book is built to grow.` / `…to hold.` / `…for income.` / `This book balances growth and ballast.` — never `Looks like Growth.` and never a Study template name (`Dogs of the Dow`, `60/40`, `All-Weather`) in the Live hero. Do not show `Also close to …`. Fit still classifies against the seven Study templates internally (score stays on the model). Under the headline, two Study-style panels: **How it’s built** (sleeve mix in one sentence) and **What has to go right** (concentration in one sentence). Reliance is 0–100 “how much one idea has to be right” (high = concentrated) using the same 12 / 20 / 35 / 60 marks as `computeConcentration` / `computeRiskFlags` — not Conviction Score, not resilience, not a health grade. Visible stake line names the weight (`NVDA is 28% of the book. That name has to work.`) — do not lead with `Reliance 74 · NVDA 28% · Tech 61%` or a swing essay. Delta header uses investor nouns (`Growth` / `Balanced` / `Defensive` / `Income`), not template names. The five pills are a **comparison target**, not a second diagnosis: a muted `Compare against →` label sits between the Fit line and the pill row (not “Risk profile”, not “What’s your risk profile?”, not “How should this book behave?”). Same five brokerage buckets as **pills** (rounded, selected fill, quiet unselected), full labels, no blurbs, no truncation: **Aggressive Growth** (max appreciation, concentrated/high-beta, accept big drawdowns → concentrated Growth book), **Growth** (core equity, leaders, diversified, not speculative → diversified Growth book), **Growth + Income** (balanced upside + dividends/cash flow → 60/40, Three-Fund, Dividend), **Defensive** (preserve capital, low-beta/staples/cash → All-Weather, Permanent), **Income** (yield first, aristocrats/fixed income, low vol → Dividend / Dogs / Permanent). Default from Fit until they pick; persist the override (`conviction-portfolio-risk-profile` in localStorage for guests). Above the rec list, a two-line delta header that updates with the pill: `{Fit label} → {selected profile}` then `Here's what would need to change:` — e.g. `Growth → Defensive`. Do not bring back `If you mean Defensive` / `riskProfileMovesLead`. Recs are category guidance, not a trade: **Trim** keeps ticker bold (`Trim NVDA`); **Add** uses a category label plus a muted representative-ETF chip (`Add ballast` + `TLT`, `Add core` + `VTI`), never a bold add ticker, and the why never names that ETF. Stack each rec (action line, then why) — do not put why in a second desktop column. Hide Keep rows when any Trim/Add exists. **Add-recs are ETFs only** — never an individual common stock as a buy (no AAPL / TSLA / GEV / JNJ pick). Growth-book gaps collapse to `QQQ` (`Add growth`); dividend / Dogs gaps collapse to `SCHD` (`Add yield`). Study sleeve ETFs (VTI, TLT, IEF, BND, GLD, VXUS, SGOV, DBC) stay themselves. Trim still names the existing holding you would reduce — that is not a stock pick. 2–4 moves, principle applied to this book (`NVDA is 100% of the book. One name is the risk.` / `The book has no rates exposure.`) — no “Add bonds (BND)”, no −8pt / sleeve / “toward 60/40”, no “it’s more than 20% of the book”. Value / Today / Largest sit **above** the Fit headline as a full-width strip (`metricsPlacement="above"`): Value is the lead figure; Today and Largest sit beside it on desktop. On phones Value is full-width, then Today + Largest on the second row so Largest never clips. Do not put the stats sidebar back on the right of the Fit copy. Hedge `A description of this book. Not a trade.` sits **directly under the rec list**, attached to the moves — not floating above the stats row. Optional quiet “Moves vs your book” on Study only when a live book exists — never replace the study ladder.
- Portfolio page wrappers (`.portfolio-page`, `.pf`, `.pf-study`) must stay `grid-template-columns: minmax(0, 1fr)` with `min-width: 0`. The Study chip row is nowrap and will otherwise blow the implicit grid column past the phone viewport; `overflow-x: hidden` on `.app-shell` then clips the right side (performance % and the ends of sentences). Do not use `overflow-wrap: anywhere` on Study copy — wrap at word boundaries.
- Live market/filings data is fetched at runtime from public third-party APIs (Yahoo Finance, SEC EDGAR, FINRA, Nasdaq). Egress to some of these (notably `data.sec.gov`) may be blocked/403 in the cloud sandbox; the app degrades gracefully but some evidence panels may be empty.
- Known pre-existing test failures unrelated to setup: `tests/company-tickers.test.ts` hits the real SEC API and fails with `403` when egress is blocked; one case in `tests/conviction-score-adapters.test.ts` ("remaps 0–100 ring…") is time-dependent (uses default July 2026 filing dates without a fixed `now`) and fails once the current date is far enough past those dates. The other ~522 tests pass.
- Optional integrations are enabled only via env vars: `DATABASE_URL` (Neon Postgres, with SQL in `migrations/`), `AUTH_SECRET` + GitHub OAuth creds (NextAuth GitHub sign-in), `KV_URL`/`KV_REST_API_URL` (Vercel KV), `FMP_API_KEY`, `GOOGLE_BOOKS_API_KEY`, `CRON_SECRET`. None are needed for local development.
