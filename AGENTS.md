## Cursor Cloud specific instructions

This is a single Next.js 16 (App Router, Turbopack) app named `conviction`. Package manager is **npm**. Standard commands live in `package.json`: `npm run dev` (port 3000), `npm run build`, `npm run typecheck` (`tsc --noEmit` — there is no ESLint/lint script), and `npm run test` / `npm run test:watch` (Vitest).

- The app runs fully in **guest mode with no external services**: no database, KV, or auth provider is required to boot and use it. Auth (`auth.ts`) falls back to JWT sessions and the watchlist persists to a local JSON file under `.conviction/` when Neon/Vercel KV env vars are absent. `npm run dev` alone is enough to exercise the product end-to-end (root `/` redirects to `/pulse`).
- Daily chrome is Pulse, Watchlist, Portfolio, News, then **Menu**. Smart Money and **Crowd** are not tab-bar items — they live under Menu → More. About and Q&A live under Menu → About, with the daily pages listed there too so new destinations scale without another bottom-bar item. Do not put Smart Money or Crowd back on the tab bar. **Sectors** and **International** live on Pulse behind a top `SurfaceSlicer` (`Markets` / `Sectors` / `International`, URL `?view=`). Do not put them back in Menu or on the tab bar. Legacy `/sectors` and `/international` permanentRedirect into Pulse. Add future pages to `menuNavPages` in `src/lib/nav-config.ts` unless they are daily. The Menu overlay is full-page (not a half sheet); `menuGroups` leads with **Your data** (Manage / Sign in), then Daily, More, About.
- **Crowd** (`/crowd`, Menu → More) is v1 network effects: classic “most held” / “most watched” across member books. Ten starter books (`crowd-seed-01`…`10` in `src/lib/crowd/seed-books.ts`) upsert into Neon when `DATABASE_URL` is set; without a DB the same fixtures power the board in memory. Aggregate only — never show who owns what. No ProductStage hero; `SurfaceSlicer` for Held / Watched; hedge that starter books fill the board while membership is small. Do not put Crowd on the tab bar yet.
- The workspace header tape is a **scrolling strip of symbols and session %**: DIA, SPY, QQQ, GLD, BTC, then five trending names. No dollar prices, no spelled-out index names, no “Markets” label, no VIX/10Y. Pause only on hover of the tape itself (not `:focus-within` — a focused quote link would freeze the strip). Honor `prefers-reduced-motion` (static, swipe to see the rest). Loop is **20s desktop / 16s phone** so motion is obvious in a short look. The site-wide reduced-motion nuke (`* { animation-duration: 0.01ms !important }`) must not win when motion is allowed — `.market-tape-track` restores duration/iteration under `prefers-reduced-motion: no-preference`. To verify motion, do **not** leave the cursor on the tape (hover pauses it). Do not put ETF share prices next to index labels.
- SEO lives in `src/lib/site.ts` + `src/lib/seo.ts`. Public search/share title is “CONVICTION — The stock market, organized around you”. Meta description must describe today’s workspace (Pulse, watchlist, portfolio, sectors/international, news, smart-money filings, Crowd) — never legacy labels like “Evidence Detection” or “Ownership Signals”. About (`/about`) and Q&A (`/faq`) live under Menu → About; keep copy in `src/lib/product-copy.ts` aligned with SEO. Pulse is the canonical home, so `/pulse` uses the brand title (absolute, no “Pulse · CONVICTION”) for Google and SMS/iMessage cards. Other routes use `pageMetadata()` so title, canonical, Open Graph, and Twitter stay in sync. Canonical host is `www.gotconviction.com` (override with `SITE_URL` / `NEXT_PUBLIC_SITE_URL`). Apex and the production Vercel alias 308 there in `next.config.ts`; `/` 308s to `/pulse`. Screen-reader `h1.sr-only` on Pulse / News / Watchlist / Portfolio / Smart Money / Crowd is intentional — do not add a visible second lede.
- Heatmaps share one tile language (no pulsing status dots, uniform tiles, one-line names with ellipsis, brokerage teal/red fills from `src/lib/display/heat-color.ts`). **Watchlist** uses the same Top/Bottom movers board as Pulse Market Movers (`MarketMoversBoard` + `splitMarketMovers`) — gainers and losers in separate columns (parity not required; empty side says “No gainers/losers yet.”), with TradingView quote stacks — not a heatmap or single index list. Do not wrap `%` in parens and do not bring back TODAY/PRE pills or magnitude bars. Sectors and International use the same index scoreboard as Pulse (name, spark, last `$`, `$`+`%`), not heatmaps — they sit on Pulse behind the Markets / Sectors / International `SurfaceSlicer` (`?view=sectors` / `?view=international`). Pulse Markets is one scroll — no Indexes/Trending `ViewSwitcher`. - Portfolio Study Mode keeps each template’s design brief (principle, how it’s built, what breaks it, illustrative history, sleeve roles) plus the allocation ladder for target weights and a concentration compare vs the live book. Historical performance cards keep colored ticks (annualized / best / worst). On phones those three stats stack as compact rows with a left tick so Worst never clips; How it’s built / What breaks it stack. Do not replace the study ladder with a plain ticker list. Do not bring back Live “pressure points” insight cards.
- Live Portfolio page order is **Hero → Sector Mix → Concentration ladder → Book vs Benchmark card (range chips + chart + Compare against pills + Trim/Add) → Holdings**. Compare against is embedded under the chart behind a divider — not a separate card. The chart benchmark ETF follows the selected profile (`PROFILE_BENCHMARK`: Aggressive Growth→QQQ, Growth→VTI, Growth+Income→SPY, Defensive→TLT, Income→SCHD); takeaway and series update when the pill or range changes. Do not hard-code SPY-only or park Compare in its own board below the chart. The colorful `ProductStage` hero is **only** Portfolio Value (solid opaque Value panel so it stands out on a softer stage shell) + a compact Today `$ (+%)` strip (optional day sparkline) + the Fit diagnosis as small muted text **under the Value figure** (not a second card, not a stage headline, not dual semicircle gauges) — e.g. `This book is built to grow.` A quiet Refresh prices / Last updated strip sits under the hero. Do not put How it’s built / What has to go right panels on Live (redundant with Sector Mix and Trim/Add). Do not put “runs the book” / “Top three run the book” back, and do not add an Insights tab or pressure-points cards. Fit classifies the live book against the seven Study templates from sleeve mix (U.S. equity / intl / bonds / gold / commodities / cash), with ticker overlap as the tie-break. Diagnosis copy is Schwab-plain: `This book is built to grow.` / `…to hold.` / `…for income.` / `This book balances growth and ballast.` — never `Looks like Growth.` and never a Study template name (`Dogs of the Dow`, `60/40`, `All-Weather`) in the Live hero. Do not show `Also close to …`. Fit still classifies against the seven Study templates internally (score stays on the model). **Sector Mix** is a 3D donut (`SectorDonut` / `DonutChart`; eyebrow `Sector Mix` only — no essay subhead, no ranked bars). **Concentration** is the allocation ladder (eyebrow `Concentration`, title `Largest positions`, keep the 12% watch / 20% concentration markers hint). Do not label either “Capital Map”. Concentration bar/weight uses the same industry colors as Sector Mix (`getSectorColor` / `sector-colors.ts`) — never P&L red (red/green stay on the today $ column only). Threshold markers still mark 12% / 20% weight. Ladder dollar change shows a muted `today` suffix. Do not park Concentration below Book vs Benchmark. Reliance is 0–100 “how much one idea has to be right” (high = concentrated) using the same 12 / 20 / 35 / 60 marks as `computeConcentration` / `computeRiskFlags` — not Conviction Score, not resilience, not a health grade. Visible stake language names the weight when used in moves (`NVDA is 28% of the book. That name has to work.`) — do not lead with `Reliance 74 · NVDA 28% · Tech 61%` or a swing essay. Delta header uses investor nouns (`Growth` / `Balanced` / `Defensive` / `Income`), not template names. The five pills are a **comparison target**, not a second diagnosis: a muted `Compare against →` label sits above the pill row (not “Risk profile”, not “What’s your risk profile?”, not “How should this book behave?”). Same five brokerage buckets as **pills** (rounded, selected fill, quiet unselected), full labels, no blurbs, no truncation: **Aggressive Growth** (max appreciation, concentrated/high-beta, accept big drawdowns → concentrated Growth book), **Growth** (core equity, leaders, diversified, not speculative → diversified Growth book), **Growth + Income** (balanced upside + dividends/cash flow → 60/40, Three-Fund, Dividend), **Defensive** (preserve capital, low-beta/staples/cash → All-Weather, Permanent), **Income** (yield first, aristocrats/fixed income, low vol → Dividend / Dogs / Permanent). Above the rec list, a two-line delta header that updates with the pill: `{Fit label} → {selected profile}` then `Here's what would need to change:` — e.g. `Growth → Defensive`. Do not bring back `If you mean Defensive` / `riskProfileMovesLead`. Recs are category guidance, not a trade: **Trim** keeps ticker bold (`Trim NVDA`); **Add** uses a category label plus a muted representative-ETF chip (`Add ballast` + `TLT`, `Add core` + `VTI`), never a bold add ticker, and the why never names that ETF. Stack each rec (action line, then why) — do not put why in a second desktop column. Trim still names the existing holding you would reduce — that is not a stock pick. 2–4 moves, principle applied to this book (`NVDA is 100% of the book. One name is the risk.` / `The book has no rates exposure.`) — no “Add bonds (BND)”, no −8pt / sleeve / “toward 60/40”, no “it’s more than 20% of the book”. Portfolio Value + a compact Today `$ (+%)` strip (parens on `%`, with day sparkline when available) sit in the hero strip (`metricsPlacement="above"`): Value is the lead figure with Fit diagnosis muted under it; Today sits beside Value on desktop. On phones Value (+ diagnosis) is full-width, then the Today strip on the second row. Do not put Largest back in the hero strip. Do not put the stats sidebar back on the right of the Fit copy. - Portfolio page wrappers (`.portfolio-page`, `.pf`, `.pf-study`) must stay `grid-template-columns: minmax(0, 1fr)` with `min-width: 0`. The Study chip row is nowrap and will otherwise blow the implicit grid column past the phone viewport; `overflow-x: hidden` on `.app-shell` then clips the right side (performance % and the ends of sentences). Do not use `overflow-wrap: anywhere` on Study copy — wrap at word boundaries.
- Live market/filings data is fetched at runtime from public third-party APIs (Yahoo Finance, SEC EDGAR, FINRA, Nasdaq). Egress to some of these (notably `data.sec.gov`) may be blocked/403 in the cloud sandbox; the app degrades gracefully but some evidence panels may be empty.
- Live SEC ticker coverage in `tests/company-tickers.test.ts` is gated behind `SEC_LIVE_TESTS=1` (data.sec.gov often 403s in sandboxes). One case in `tests/conviction-score-adapters.test.ts` ("remaps 0–100 ring…") is time-dependent (default July 2026 filing dates without a fixed `now`) and can fail once the calendar moves far past those dates. Cron / full evidence refresh / admin resources require `CRON_SECRET` (fail closed); single-ticker evidence refresh stays available for company pages.
- Optional integrations are enabled only via env vars: `DATABASE_URL` (Neon Postgres, with SQL in `migrations/`), `AUTH_SECRET` + Google OAuth creds (NextAuth Google sign-in), `KV_URL`/`KV_REST_API_URL` (Vercel KV), `FMP_API_KEY`, `GOOGLE_BOOKS_API_KEY`, `CRON_SECRET`. None are needed for local development.
