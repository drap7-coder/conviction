# CONVICTION — Who’s buying the stocks you follow

Follow the stocks you care about. See what institutions, insiders, and politicians are buying and selling — and what changed today.

## Getting Started

```bash
npm install
npm run dev
```

Optional env:

```bash
# Broader earnings coverage (FMP primary, Nasdaq fallback)
FMP_API_KEY=your_key_here
```

## Product surfaces

- **Watchlist / Portfolio** — Companies and holdings you follow
- **Pulse** — Indexes, trending, commodities, and sectors
- **Smart Money** — Institutional 13F moves and political disclosures

## Data Sources (V1)

- SEC EDGAR (fixtures)
- Market price feed (fixtures)
- USAspending (fixtures)
