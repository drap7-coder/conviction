# Bundled site fonts

Unmodified Latin variable WOFF2 subsets of IBM Plex Sans v23 and JetBrains Mono v24, downloaded from Google Fonts on November 5, 2026. Used with next/font/local at weights 400–700 to remove the build-time Google Font fetch and its recurring Turbopack resolver failure. Existing CSS variable names and font-display: swap are retained. Other scripts use the existing fallback stack.

Source stylesheet: https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400..700&family=JetBrains+Mono:wght@400..700&display=swap

Both families use the SIL Open Font License; full notices are included alongside the binaries.
